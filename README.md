# Fouad & Hala — Wedding Invitation

دعوة زفاف إلكترونية Static جاهزة لـ GitHub Pages، بدون صور خارجية. التصميم مبني بالكامل بـ HTML/CSS/JS ويستخدم ملف الموسيقى داخل `assets`.

## التعديل السريع
كل بيانات العروسين والتاريخ والمكان وبرنامج الحفل ورابط الخريطة موجودة في `config.js` فقط.

## النشر على GitHub Pages
1. أنشئ Repository باسم `fouad-hala-Wedding`.
2. ارفع محتويات هذا المجلد إلى الفرع `main`.
3. من Settings → Pages اختر Deploy from a branch ثم `main` و `/root`.
4. سيظهر رابط الدعوة بعد اكتمال النشر.

> ملاحظة: المتصفحات تمنع تشغيل الصوت تلقائياً غالباً، لذلك يبدأ بعد أول لمسة/نقرة من الضيف أو عبر زر الموسيقى.
